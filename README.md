  - Tebakan benar: efek kembang api
  - Tebakan dalam jarak 5: efek bintang biru
  - Tebakan dalam jarak 20: efek awan biru tua
  - Tebakan dalam jarak 50: efek gelap
  - Tebakan paling jauh: teks merah menyala di latar hitam
